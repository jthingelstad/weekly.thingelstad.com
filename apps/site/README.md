# apps/site/ — Eleventy static site

The Eleventy site at [weekly.thingelstad.com](https://weekly.thingelstad.com): landing page, full archive, feeds, search, FAQ, ops report.

> Operational memory for editing the site lives in [`CLAUDE.md`](CLAUDE.md). This README is the human-facing reference.

## Run

```bash
# from the repo root
make serve         # dev server (eleventy --serve)
make build         # production build → _site/
```

Eleventy is invoked from the repo root with `--config apps/site/eleventy.config.js`. The output dir `_site/` stays at the repo root so CI's `upload-pages-artifact` step picks it up unchanged.

## Layout

```
apps/site/
├── README.md             ← this file
├── CLAUDE.md             ← operational memory
├── eleventy.config.js    ← passthroughs, filters, collections, markdown setup
├── _data/                ← JSON + JS data files (mix of hand-authored + generated)
│   ├── emails.json       ← (generated) lightweight issue index
│   ├── stats.json        ← (generated) subscriber + Stripe figures
│   ├── status.json       ← (generated) per-issue pipeline state for /ops/
│   ├── voiceSamples.json ← (generated by `make refresh-copy`) home-page pull-quotes
│   ├── site.js           ← (hand-authored) URL, author, social, Tinylytics UID
│   ├── support.json      ← (hand-authored) current + past nonprofits
│   ├── quotes.json       ← (hand-authored) reader-survey testimonials
│   ├── survey.json       ← (hand-authored) reader survey stats
│   ├── archiveStats.js   ← (computed at build) totals, records, streaks
│   ├── supportTotals.js  ← (computed at build) supporter program totals
│   ├── faq.js            ← (re-export) shares FAQ source with the Thingy Lambda
│   ├── redirects.js, topics.js, assets.js
├── _includes/
│   ├── layouts/          ← page layouts (base, archive, etc.)
│   └── partials/         ← shared snippets (header, footer, subscribe form, …)
├── archive/              ← {N}.md per issue — generated by `pipeline/content/content.py build`
├── css/                  ← style.css
├── img/                  ← static images (passthrough)
├── index.njk, about.njk, support.njk, search.njk, faq.njk, …
├── feed.njk, issue-links-feed.njk, podcast.njk
├── librarian.njk, ops.njk, status-json.njk, redirects.njk
└── CNAME, robots.txt, _nojekyll, favicon.svg
```

**Don't hand-edit `apps/site/archive/*.md`** — they're generated. Edit the canonical body in `data/issues/{N}/archive.md` and run `make build`.

## Pages

| Path | Template | What it is |
|---|---|---|
| `/` | `index.njk` | Landing page — hand-written |
| `/archive/` | `archive/archive.njk` | Year-grouped issue index |
| `/archive/N/` | Generated `{N}.md` | Issue page with TOC, domains, prev/next |
| `/about/` | `about.njk` | Bio + story |
| `/members/` | `support.njk` | Supporting Membership |
| `/search/` | `search.njk` | Pagefind search |
| `/faq/` | `faq.njk` | FAQ |
| `/feed.xml` | `feed.njk` | Atom feed |
| `/archive/N/links.xml` | `issue-links-feed.njk` | Per-issue links feed |
| `/podcast.xml` | `podcast.njk` | Podcast RSS |
| `/librarian/` | `librarian.njk` | Thingy chat interface |
| `/ops/`, `/status.json` | `ops.njk`, `status-json.njk` | Unlinked, noindex pipeline state |

## Design

Editorial, magazine-like. Source Serif 4 for display + italic accents, Source Sans 3 for body/UI, JetBrains Mono for eyebrows and meta. Generous whitespace. `#fcfcfa` bg, `#1f6fd6` accent. Dark mode via `prefers-color-scheme`. Mobile-first, accessible (heading hierarchy, alt text, color contrast, keyboard nav). No JS required for core reading.

## Search

[Pagefind](https://pagefind.app/) runs **after** the Eleventy build, indexes the built HTML in `_site/`. CI runs `npx pagefind --site _site` as a separate step.
